# Weekly executive brief

Prepare a Monday executive brief covering the previous week and the week ahead.

1. Summarize material workforce and finance changes from the two SAP MCP servers.
2. Review major decisions, unresolved actions, risks, and commitments from authorized Microsoft 365 context.
3. Show the six agreed SAP KPIs only when their source calls succeed.
4. Evaluate actual versus target using versioned rules.
5. Include approved peer benchmarks only when cohort, period, methodology, and license are available.
6. Rank this week's priorities and decisions due.
7. Return an Executive Brief card plus concise text, sources, warnings, and correlation ID.

Never invent a KPI, benchmark, decision, owner, deadline, or completion state.
